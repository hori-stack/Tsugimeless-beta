HoriCraft · テスター向け

首の境目を、
ツギメレスで確かめる。

顔を見本に、体側の首まわりだけをなじませるUnityツールです。まずは上下の線が置けるところまで試してください。

テスト版です。作業中のプロジェクトをバックアップし、テスト用のコピーで使ってください。アバターやlilToonは含まれていません。

1配布リポジトリを追加する

VCCまたはALCOMをインストールしたPCで開いてください。

VCC / ALCOMに追加する

  1. 表示されたリポジトリ名が「HoriCraft ツギメレス テスト版」か確かめ、追加します。
  2. テスト用のUnityプロジェクトを選び、パッケージの管理画面を開きます。
  3. 「ツギメレス (Beta)」の 0.2.0-beta.2 を追加します。見えない場合は、設定でプレリリース版の表示を有効にします。VCCでは「Show Pre-Release Packages」です。
  4. lilToonを別途導入してから、Unityを開きます。

検証環境: Unity 2022.3.22f1 / Built-in / Linear / lilToon 2.3.4。Unity 6は未検証です。同じ名前の開発パッケージをfile参照で入れている場合は、そのまま重ねて追加しないでください。

2まずは上下の線まで

  1. Unityの上のメニュー HoriCraft → ツギメレス を開きます。
  2. Hierarchyから、アバター全体を選択欄へドラッグします。
  3. 「上下の範囲」へ進み、水色の上の線と黄色の下の線を矢印で動かします。
  4. 「次へ：見た目」で体験版の案内が出れば、キーなしの確認は完了です。

線が出ない場合は、表示された理由をそのまま教えてください。無理にアバターを作り直す必要はありません。

3キーを受け取ったら、見た目を比べる

テスト依頼者から受け取ったツギメレス用の解除キーを、設定タブへ入力して登録します。キーは返信やスクリーンショットへ写さないでください。

  1. 「首をなじませる」へ戻り、「見た目」で色を計算します。
  2. 補正前と補正後を切り替え、正面・横・後ろから首を見ます。
  3. 「仮表示を終了する」で元の表示に戻します。計算結果は残るので、補正後をもう一度表示できます。
  4. よければ「適用」へ進み、対象を確認して仕上がりを適用します。次回も使うにはUnityでシーンを保存してください。
  5. 「あとから戻す」で元の状態と、今回の仕上がりをそれぞれ確認します。

肌色の差が減るかを確認するテストです。影・輪郭線・形が原因の境目は残る場合があります。今回の結果を自動的に「対応済み」とは扱いません。

困ったときの返信

使ったアバター名と版、どの工程で困ったかを依頼者へ伝えてください。

設定 → テスト結果を伝える → 検証情報を表示するで内容を確認し、「この内容をコピーする」から返信へ貼り付けられます。キー・PC名・保存先は含めません。自動送信はしません。

購入テクスチャ・アバターデータ・解除キーは添付しないでください。スクリーンショットを送る場合も、キー欄や個人情報を写さないでください。

今回、分かっていること

今回の検証個体機械検証の結果
Milltina / Ramune / Alue / Sio / LUMINA上下の線・色計算・保存画像の確認まで通過。自然な仕上がりはテスター確認が必要です。
Suzuya / Shinano / Kipfel / rurune首の輪が確定せず停止。今回の版ではこの結果です。

同じアバター名でも、版や改変内容で結果が変わります。最初の体の肌スロットが対象です。元の画像と材質は残し、適用ごとに画像を保存するため容量は増えます。外部で変更・削除したファイルを履歴から取り戻す機能ではありません。
